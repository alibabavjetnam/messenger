# z-docs-code-comment

Thuộc agent: `az-docs`

## Mục đích
Chú thích code.

## Các bước
1. Giải thích 'tại sao', không lặp lại 'cái gì'.
2. Sửa hoặc xóa comment cũ đã sai.

## Đầu ra
Comment trong code.

## Hoàn thành khi
- Đầu ra đã được ghi vào đúng file.
- Report có bằng chứng thực tế (output lệnh), không chỉ mô tả.
- Mọi điểm cần người dùng quyết định đã được chuyển về `saz-orchestrator`.
