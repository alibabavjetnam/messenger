# z-tester-unit-test

Thuộc agent: `az-tester`

## Mục đích
Viết unit test.

## Các bước
1. Dùng framework dự án đang dùng.
2. Mẫu Arrange – Act – Assert; mỗi test kiểm một điều.
3. Mock phụ thuộc ngoài; test độc lập, chạy thứ tự nào cũng được.

## Đầu ra
File test + output.

## Hoàn thành khi
- Đầu ra đã được ghi vào đúng file.
- Report có bằng chứng thực tế (output lệnh), không chỉ mô tả.
- Mọi điểm cần người dùng quyết định đã được chuyển về `saz-orchestrator`.
