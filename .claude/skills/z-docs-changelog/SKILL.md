# z-docs-changelog

Thuộc agent: `az-docs`

## Mục đích
Ghi changelog.

## Các bước
1. Theo định dạng Keep a Changelog: Added / Changed / Fixed / Removed / Security.
2. Liên kết tới BUG id hoặc task id.

## Đầu ra
`CHANGELOG.md`.

## Hoàn thành khi
- Đầu ra đã được ghi vào đúng file.
- Report có bằng chứng thực tế (output lệnh), không chỉ mô tả.
- Mọi điểm cần người dùng quyết định đã được chuyển về `saz-orchestrator`.
